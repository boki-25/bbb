# 遇见 · GitHub交友网站演示版

这是只使用 GitHub Pages 的交友/相亲网站交互演示，可直接替换仓库根目录文件运行。

## 已有功能

- 18岁以上本机体验账号
- 发布和修改个人资料
- 按性别、城市浏览资料
- 喜欢、互相匹配、聊天
- 举报、拉黑与安全提示
- 管理员名称 `lbbaaa`
- 本机后台查看账号、匹配数、消息数量和举报
- 本机后台停用、恢复或删除体验账号
- 管理员操作记录
- 手机和电脑自适应

## 重要限制

GitHub Pages 没有服务器和数据库。因此这个版本的数据只保存在当前浏览器：

- 不同手机上的账号不能互相看到；
- 不同用户不能进行真实聊天；
- 管理员看不到其他设备的注册资料；
- 后台登录只是本机演示保护，不是真正的服务器管理员权限；
- 清理浏览器数据后，本机账号和聊天可能消失。

如果需要真正多人注册、公开资料、互相匹配和实时聊天，必须增加 Supabase、Firebase 或自建服务器。

## 管理员登录

管理员名称固定为：

```text
lbbaaa
```

首次打开 `admin.html` 时，需要在当前浏览器设置至少10位的新口令。不会使用 `200625`，因为公开GitHub代码无法安全保存密码，而且该密码过短。

## 上传到GitHub

1. 解压压缩包；
2. 打开 `boki-25/bbb`；
3. 点击“转到文件”右侧的灰色 `+`；
4. 选择“上传文件”；
5. 上传 `.nojekyll`、`index.html`、`admin.html`、`config.json` 和 `README.md`；
6. 新文件必须位于仓库根目录；
7. 点击绿色“提交更改”；
8. 等待GitHub Pages出现绿色对勾。

网站地址：

```text
https://boki-25.github.io/bbb/
```

本机管理后台：

```text
https://boki-25.github.io/bbb/admin.html
```

## 上线真实版本前必须完成

- 邮箱或手机号验证；
- 数据库行级权限；
- 图片安全审核；
- 举报与申诉流程；
- 管理员强密码和双因素认证；
- 隐私政策、用户协议和数据删除；
- 防骚扰、反诈骗和未成年人保护；
- 管理员操作审计；
- 限制管理员随意读取私人聊天，仅在举报或依法处理时访问必要内容。
