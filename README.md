# GitHub Pages 反诈体验网站

这是专门为 `boki-25/bbb` 仓库准备的纯静态版本，不需要服务器、数据库、Docker 或命令行。

## 第一次上传

压缩包解压后只有以下主要文件：

- `index.html`：居民访问的反诈体验前台
- `admin.html`：生成网站配置的管理页面
- `config.json`：全站标题、积分和教学内容
- `README.md`：本说明

请把这些文件直接上传到 `bbb` 仓库最外层，和现在的 `index.html` 放在同一级。新的 `index.html` 需要替换旧文件，不要把整个文件夹再套一层上传。

操作步骤：

1. 打开 GitHub 仓库 `boki-25/bbb`。
2. 点击“添加文件”→“上传文件”。
3. 把解压后的 `index.html`、`admin.html`、`config.json` 和 `README.md` 拖进去。
4. 页面提示重名时保留新文件。
5. 点击底部绿色“提交更改”按钮。
6. 等待 GitHub Pages 重新部署，然后刷新网站。

## 修改网站内容

打开网站地址后，在网址最后把 `index.html` 改成 `admin.html`，例如：

```text
https://boki-25.github.io/bbb/admin.html
```

在管理页面修改内容，点击“下载 config.json”，然后回到 GitHub 仓库上传并替换根目录的 `config.json`。

## GitHub Pages 版本限制

GitHub Pages 只能发布静态网页，因此：

- 没有真正的服务器后台和数据库；
- 不能创建跨设备同步的账号；
- 昵称、积分和学习记录只保存在访客当前手机或电脑的浏览器中；
- 管理页不能直接保存到 GitHub，需要下载并重新上传 `config.json`；
- 不应添加充值、提现、支付或现金兑换功能。

这套设计适合社区现场宣传、二维码访问和反诈教学演示。如果以后需要统一统计所有居民数据，再增加服务器即可。

## 更新没有显示怎么办

1. 打开仓库右侧“部署”区域，确认最新 GitHub Pages 部署出现绿色对勾；
2. 手机或电脑浏览器强制刷新；
3. 等待几分钟后重新打开；
4. 确认文件上传在仓库根目录，而不是某个文件夹里面。
